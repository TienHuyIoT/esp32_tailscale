# ISUI Reusable Web Design Kit

Reusable design and implementation standards for new websites and UI refactors.

## Contents
- `DESIGN_SYSTEM.md` — visual language and quality bar.
- `IMPLEMENTATION_RULES.md` — engineering constraints and verification rules.
- `PROJECT_BRIEF.md` — copy/update for each project.
- `PROMPT_TEMPLATES.md` — prompts for planning, autonomous execution, refactoring, and review.
- `reference/ISUI_REFERENCE.html` — primary glassmorphism/control-dashboard visual reference.
- `reference/ISUI_SPACE_SCENE_REFERENCE.html` — supplementary space/planet scene reference.

## How to use
1. Copy this folder into a repository, or copy the four Markdown files plus `reference/`.
2. Update `PROJECT_BRIEF.md` for the specific project.
3. Ask your coding agent to read `DESIGN_SYSTEM.md`, `IMPLEMENTATION_RULES.md`, `PROJECT_BRIEF.md`, and inspect the HTML references before coding.
4. For an existing website, choose plan-first mode unless you explicitly want autonomous execution.
5. Keep reference HTML as a visual guide. Its interactions are demo-only and do not represent a real backend/device integration.

## Preview
Open either HTML reference directly in a modern browser. The primary reference is a self-contained HTML prototype; the space scene reference is an additional visual direction, not a requirement for every project.
